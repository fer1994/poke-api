# Ejecutar en desarrollo

1. Clonar el respositorio
2. Ejecutar

```
pnpm install
```

3. Tenes NEST CLI instalado 
``
https://nestjs.com/
``
4. Levantar la base de datos

```
docker-compose -d
````
